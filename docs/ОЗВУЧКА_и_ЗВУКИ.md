# Кедр-7 — что сгенерировать (озвучка и звуки)

Код уже готов. Сейчас реплики идут субтитрами, а как только появится файл с голосом, реплика зазвучит сама — дописывать ничего не нужно. Файлы можно докладывать постепенно.

Что делать: сгенерируй файлы из списка, назови их **ровно как в колонке «Файл»** и положи в папку `kedr7/voice_src/` (озвучка) и `kedr7/sfx_src/` (звуки). Формат любой: mp3 или wav.

Дальше всё делаю я (или сам: `python tools/process_voice.py` из папки игры, нужен ffmpeg):
- радиофильтр (полоса 300–3000 Гц, треск, плавание частоты);
- нормализация громкости;
- конвертация в OGG;
- подключение в игру с субтитрами RU/EN.

Эффекты при генерации **не накладывай**: нужен чистый голос, «рацию» сделаю я.

Голоса берём из тех, что у тебя уже есть в ElevenLabs (их видно по файлам в `music/`). Озвучка только русская, в EN-версии будут английские субтитры. Так атмосфернее, чем делать английский дубляж.

**Настройки ElevenLabs:**
- модель Multilingual v2 (или v3, если есть — там работают теги `[whispers]`, `[tired]`);
- Stability 35–45 % — живее и неровнее;
- Similarity 75 %;
- Style 0–15 %.

Из каждой реплики сгенерируй 2–3 дубля и оставь лучший. Если сомневаешься, клади все дубли с суффиксами `_a`, `_b` — выберу сам.
