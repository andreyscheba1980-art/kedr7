# Сервер комнат для коопа «Две вахты»

Без него напарники подключаются по IP-адресу. Это работает в одной сети, через Radmin VPN/ZeroTier
или если у хоста открыт порт. С сервером комнат хост получает короткий код (например `K7X2QM`),
второй игрок вводит его. Сервер сам пробивает NAT, а если не вышло (мобильный интернет, CGNAT), гонит
трафик через себя. Игре нужно примерно 25 КБ/с на пару игроков с голосом.

Сервер — [noray](https://github.com/foxssake/noray) (MIT), готовый Docker-образ. Хватит самого дешёвого
VPS с 1 ядром и 512 МБ памяти, нужен публичный IPv4.

## Установка (Ubuntu/Debian на VPS)

1. Поставить Docker: `curl -fsSL https://get.docker.com | sh`
2. Скопировать на сервер папку `tools/noray` (docker-compose.yaml и .env), например в `/opt/kedr7-rooms`.
3. Запустить: `cd /opt/kedr7-rooms && docker compose up -d`
4. Открыть порты в файрволе VPS (и в панели хостера, если там свой файрвол):
   - TCP 8890 — команды
   - UDP 8809 — регистрация адресов
   - UDP 49152–49351 — ретранслятор

   Для ufw: `ufw allow 8890/tcp && ufw allow 8809/udp && ufw allow 49152:49351/udp`
5. Проверить: `docker logs kedr7-rooms` — в конце строка «Started noray».

## Подключить игру

В `scripts/autoload/net.gd` вписать адрес сервера:

```gdscript
const ROOM_SERVER := "rooms.example.ru"   # или IP: "95.12.34.56"
```

и пересобрать игру. Кнопки «по коду» появятся в меню «Две вахты».
Для проверки без пересборки: файл `%APPDATA%\Godot\app_userdata\Кедр-7\net.cfg`

```ini
[rooms]
host="95.12.34.56"
port=8890
```

## Что важно знать

- Сервер не хранит ничего, кроме кодов активных комнат. Голос и данные игры идут напрямую между
  игроками. Через сервер они идут только в режиме ретранслятора, и там он их не читает и не пишет.
- Обновить сервер: `docker compose pull && docker compose up -d`.
- Ограничение трафика на пару в .env (128 КБ/с) с запасом покрывает голос и позы. Если поднимать —
  то только вместе с общим лимитом.
